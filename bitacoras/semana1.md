# Bitacora Semana 01
¿Cual es el problema?

El problema consiste en diseñar e implementar de forma incremental una solucion tecnologica en phynton que permita procesar y clasificar un registro de datos numericos , aplicando desde el primer momento buenas practicas de desarrolo con git y github.

¿Que datos recibe datalab?

En esta primera version, el sistema recibe dos datos fundamentales ingresados por consola: un identificador unico de registro y una cantidad numerica

Que debe hacer con esos datos? 

Debe capturar los valores de entrada aplicar una condicion logica para evaluarlos frente a un umbral determinado , y asignarles una categoria o etiqueta segun el resultado de la comparacion.

¿Que resultados debe producir?

Un reporte claro y formateado en pantalla que desglose el identificador de registro, el valor numerico ingresado y la etiqueta de clasificacion final obtenido.

¿Que reglas debe seguir?

cumplir con la ruta de construccion incremental problema--> algoritmo--> pseudocodigo--> diagrama--> phyton--> Git--> github.

aplicar la logica de negocio indicada si el valor es mayor o igual a 50,clasificar como "ALTO" de lo contrario "NORMAL"

estructurar y gestionar el desarollo de manera individual utilizando git local y un repositorio remoto en github

¿Que entra?

imaginate que llegamos a una ventanilla y entregamos dos cosas sencillas: un codigo o nombre para identificar el registro, y un numero que representa la metrica o cantidad que queremos evaluar.

¿Que sucede?

una vez que el sistema recibe esos datos,el algoritmo actua como un manual de instrucciones toma el numero ingresado y lo compara con un limite establecido si el numero es mayor o igual a 50 ese limite , le asigna la etiqueta "ALTO"
si es menor le asigna la etiqueta "NORMAL"
Con esto la infirmacionqueda organizada y lista para reportarse.

¿Que sale?

finalmente, el sistema imprime en la pantalla un resumen limpio que muestra el identificador del registro, el valor original que escribimos y la etiqueta definitiva que determino el proceso.
